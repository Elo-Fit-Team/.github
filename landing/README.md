# EloFit Landing & Admin Dashboard

Готовый промо-сайт с формой регистрации и закрытой админ-панелью для фиксации пользователей (**кто, когда и во сколько зарегистрировался**).

---

## 🚀 Быстрый запуск локально

Сервер работает на стандартном Python 3 (без установки библиотек):

```bash
python landing/server.py 3000
```

* **Главная страница для пользователей:** [http://localhost:3000/](http://localhost:3000/)
* **Панель администратора (база):** [http://localhost:3000/admin.html](http://localhost:3000/admin.html)
* **Пароль для входа в админку:** `elofit2026`

Все регистрации автоматически сохраняются в файл `landing/registrations.json`.

---

## 🌐 Как бесплатно захостить сайт в интернете

### Вариант 1: Vercel (Рекомендуется, 1-2 минуты)
1. Установите Vercel CLI (если не установлен) или зайдите на [vercel.com](https://vercel.com):
   ```bash
   npx vercel
   ```
   В настройках укажите папку проекта: `./landing`.
2. Либо привяжите ваш GitHub-репозиторий на сайте Vercel:
   - Добавьте проект
   - В поле **Root Directory** выберите `landing`
   - Нажмите **Deploy**
3. Вы получите готовый бесплатный адрес с HTTPS: `https://elofit-app.vercel.app`.

### Вариант 2: Netlify (Drag & Drop)
1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите папку `landing` мышкой в окно браузера.
3. Сайт моментально запустится и выдаст публичную ссылку.

## ⚡ Функционал админ-панели (`admin.html`)

1. **Точная фиксация времени:** Сохраняются дата, час, минута и секунда каждой заявки.
2. **Метрики в реальном времени:** Всего атлетов, зарегистрировано сегодня, за последний час, популярная цель.
3. **Поиск и фильтры:** По имени, email, нику в Telegram, целям и уровням подготовки.
4. **Экспорт в Excel / CSV:** Кнопка «📥 Экспорт в Excel / CSV» скачивает файл с UTF-8 кодировкой.
5. **Оповещения в Telegram:** В окне «✈️ Telegram бот» можно указать токен бота и Chat ID — и каждая новая регистрация будет мгновенно прилетать вам в личные сообщения или рабочий чат.
