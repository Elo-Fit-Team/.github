## 1. Базовые определения
**Граф** $G = (V, E)$ состоит из:
* $V$ — непустое конечное множество **вершин** (vertices / nodes), $|V| = n$.
* $E$ — множество **рёбер** (edges), соединяющих пары вершин, $|E| = m$.
  * В неориентированном графе ребро — неупорядоченная пара $\{u, v\}$.
  * В ориентированном графе (орграфе) ребро (дуга) — упорядоченная пара $(u, v)$, где $u$ — начало, $v$ — конец.

### Смежность и Инцидентность:
* Две вершины $u$ и $v$ называются **смежными**, если они соединены ребром $(u, v) \in E$.
* Ребро $e = (u, v)$ и вершина $u$ называются **инцидентными**.

---

## 2. Степень вершины
**Степень вершины** $v$ (обозначается $\deg(v)$ или $d(v)$) — количество ребер, инцидентных данной вершине (петли учитываются дважды).
* Вершина со степенью $0$ называется **изолированной**.
* Вершина со степенью $1$ называется **висячей** (листом).

### Лемма о рукопожатиях (Handshaking Lemma):
> Сумма степеней всех вершин любого графа равна удвоенному числу его рёбер:
> $$\sum_{v \in V} \deg(v) = 2 \cdot |E|$$

**Следствие:** В любом графе число вершин нечётной степени всегда **чётно**.

## 3. Способы представления графов в памяти ЭВМ

### 3.1. Матрица смежности (Adjacency Matrix)
Квадратная матрица $A$ размера $n \times n$:
$$A_{ij} = \begin{cases} 1, & \text{если между } v_i \text{ и } v_j \text{ есть ребро/дуга} \\ 0, & \text{иначе} \end{cases}$$

**Свойства:**
1. Для неориентированного графа матрица $A$ **симметрична** относительно главной диагонали ($A = A^T$).
2. На главной диагонали стоят нули (если нет петель).
3. Сумма элементов $i$-й строки равна степени вершины $v_i$.
4. **Важнейшее свойство:** Элемент $(A^k)_{ij}$ матрицы $A$, возведенной в степень $k$, равен числу различных маршрутов длины $k$ между вершинами $v_i$ и $v_j$.
* Память: $\Theta(n^2)$.
* Проверка наличия ребра: $O(1)$.

---

### 3.2. Матрица инцидентности (Incidence Matrix)
Прямоугольная матрица $B$ размера $n \times m$ (строки — вершины, столбцы — рёбра):

#### Для неориентированного графа:
$$B_{ij} = \begin{cases} 1, & \text{если вершина } v_i \text{ инцидентна ребру } e_j \\ 0, & \text{иначе} \end{cases}$$
* Каждый столбец содержит ровно **две единицы** (концы ребра).

#### Для ориентированного графа:
$$B_{ij} = \begin{cases} -1, & \text{если вершина } v_i \text{ — начало дуги } e_j \\ 1, & \text{если вершина } v_i \text{ — конец дуги } e_j \\ 0, & \text{если вершина не инцидентна дуге} \end{cases}$$
* Каждый столбец содержит ровно одну $-1$ и одну $+1$.

---

### 3.3. Список смежности (Adjacency List)
Массив или хэш-таблица, где для каждой вершины хранится список её соседей.
* Память: $O(n + m)$.
* Идеально подходит для разреженных графов ($m \ll n^2$).

---

## 4. Код генератора матриц (из учебной практики)
```python
def build_adjacency_matrix(n, edges, directed=False):
    matrix = [[0] * n for _ in range(n)]
    for u, v in edges:
        matrix[u][v] = 1
        if not directed:
            matrix[v][u] = 1
    return matrix

def build_incidence_matrix(n, edges, directed=False):
    matrix = [[0] * len(edges) for _ in range(n)]
    for j, (u, v) in enumerate(edges):
        if directed:
            matrix[u][j] = -1
            matrix[v][j] = 1
        else:
            matrix[u][j] = 1
            matrix[v][j] = 1
    return matrix
```
