## 1. Теория множеств
**Множество** — базовое понятие, совокупность определенных и различимых объектов (элементов множества), мыслимая как единое целое.

### 1.1. Способы задания множеств:
1. **Перечислением элементов (экстенсионально):** $A = \{2, 4, 6, 8\}$
2. **Описанием характеристического свойства (интенсионально):** $A = \{x \in \mathbb{N} \mid x \text{ четное}, x \le 8\}$

### 1.2. Основные операции над множествами:
Пусть заданы множества $A$ и $B$ в универсальном множестве $U$:
* **Объединение:** $A \cup B = \{x \mid x \in A \lor x \in B\}$
* **Пересечение:** $A \cap B = \{x \mid x \in A \land x \in B\}$
* **Разность:** $A \setminus B = \{x \mid x \in A \land x \notin B\}$
* **Симметрическая разность:** $A \oplus B = (A \setminus B) \cup (B \setminus A)$
* **Дополнение:** $\overline{A} = U \setminus A = \{x \in U \mid x \notin A\}$

### 1.3. Мощность множества (Cardinality):
* Обозначается $|A|$ — число элементов множества.
* Множество всех подмножеств (булеан) $\mathcal{P}(A)$ содержит $2^{|A|}$ элементов.

## 2. Кортежи и Декартово произведение
* **Упорядоченная пара (кортеж):** $(a, b)$, где важен порядок следования элементов: $(a, b) \neq (b, a)$ при $a \neq b$.
* **Декартово (прямое) произведение:**
  $$A \times B = \{(a, b) \mid a \in A, b \in B\}$$
  Мощность: $|A \times B| = |A| \cdot |B|$.

---

## 3. Бинарные отношения
**Бинарным отношением** $R$ между множествами $A$ и $B$ называется любое подмножество их декартова произведения:
$$R \subseteq A \times B$$
Если $A = B$, то говорят об отношении $R$ на множестве $A$. Запись $a R b$ означает $(a, b) \in R$.

### 3.1. Способы представления отношений:
1. **Списком упорядоченных пар.**
2. **Матрицей отношения** $M_R = [m_{ij}]$, где:
   $$m_{ij} = \begin{cases} 1, & \text{если } (a_i, a_j) \in R \\ 0, & \text{иначе} \end{cases}$$
3. **Ориентированным графом (орграфом):** вершины — элементы множества, дуги — пары, входящие в отношение.

---

## 4. Фундаментальные свойства бинарных отношений
Отношение $R$ на множестве $A$ называется:
1. **Рефлексивным:** $\forall x \in A: (x, x) \in R$ (на главной диагонали матрицы — единицы).
2. **Антирефлексивным (иррефлексивным):** $\forall x \in A: (x, x) \notin R$ (на диагонали — нули).
3. **Симметричным:** $\forall x, y \in A: (x, y) \in R \implies (y, x) \in R$ (матрица симметрична относительно главной диагонали: $M = M^T$).
4. **Антисимметричным:** $\forall x, y \in A: ((x, y) \in R \land (y, x) \in R) \implies x = y$.
5. **Транзитивным:** $\forall x, y, z \in A: ((x, y) \in R \land (y, z) \in R) \implies (x, z) \in R$.

---

## 5. Важнейшие классы отношений
### 5.1. Отношение эквивалентности
Отношение $R$ называется **отношением эквивалентности**, если оно одновременно:
$$\text{Рефлексивно} + \text{Симметрично} + \text{Транзитивно}$$
* **Теорема о факторизации:** Любое отношение эквивалентности разбивает множество $A$ на непересекающиеся **классы эквивалентности**.

### 5.2. Отношение частичного порядка (Порядок)
Отношение $R$ называется **отношением частичного порядка**, если оно:
$$\text{Рефлексивно} + \text{Антисимметрично} + \text{Транзитивно}$$
* Пример: отношение делимости на целых числах $a \mid b$, отношение включения множеств $A \subseteq B$.

## 6. Реализация на Python
```python
# Множества в Python
A = {1, 2, 3, 4}
B = {3, 4, 5, 6}

print("Объединение:", A | B)
print("Пересечение:", A & B)
print("Разность:", A - B)
print("Симметрическая разность:", A ^ B)

# Отношение как множество кортежей
R = {(1, 1), (2, 2), (3, 3), (1, 2), (2, 1)}

def is_reflexive(R, A):
    return all((x, x) in R for x in A)

def is_symmetric(R):
    return all((y, x) in R for (x, y) in R)

def is_transitive(R):
    return all((x, z) in R for (x, y1) in R for (y2, z) in R if y1 == y2)

print("Рефлексивно?:", is_reflexive(R, {1, 2, 3}))
print("Симметрично?:", is_symmetric(R))
print("Транзитивно?:", is_transitive(R))
```
